# Instagram İndirici – Chrome eklentisi

1. Zip'i bir klasöre çıkar.
2. Chrome'da `chrome://extensions` aç, **Geliştirici modu**nu aç.
3. **Paketlenmemiş öğe yükle** (Load unpacked) → çıkardığın klasörü seç.
4. Instagram'a giriş yap, eklenti simgesine (ya da sayfadaki "İİ İndir" düğmesine) bas.
5. Profil adını yaz, **Başlat**'a bas. Açılan Instagram penceresini kapatma/küçültme.

Dosyalar `İndirilenler / Instagram Indirici / <profil>` içine iner.
